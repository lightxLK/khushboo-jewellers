Integration Framework

Follow these technical guidelines for consistent data mapping.

1
Schema Validation
Download and use the official spreadsheet template to align with our backend relational requirements.
2
Resource Linking
Child records (Products) MUST point to valid parent codes (Sub-Categories) identified in preceding sheets.
3
Media Handshake
Asset filenames must exactly match the SKU codes provided in the spreadsheet for automatic synchronization.
